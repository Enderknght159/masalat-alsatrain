# مسألة السطرين

موقع تعليمي تفاعلي يشرح **مسألة السطرين** في الكيمياء لطلاب الصف التاسع في سوريا.

**النسخة المنشورة:** https://enderknght159.github.io/masalat-alsatrain/

## طريقة السطرين

تحت المعادلة الموزونة يُكتب سطران:

1. **السطر العام:** الكتلة المولية × المعامل لكل مادة، ويُضاف الحجم المولي 22.4 L/mol تحت كل غاز.
2. **السطر الثاني:** كتلة المعطى تحت مادته، والمجهول `x` تحت المادة المطلوبة.

ثم يُكتب التناسب بين السطرين ويُحل.

## ما فيه

- درس من ست خطوات مع أسئلة فهم سريعة.
- مختبر لحل المسائل: اختيار التفاعل، تغيير الكتلة المعطاة والمادة المطلوبة، وعرض السطرين والتناسب خطوة بخطوة.
- ورشة مكعبات من ثلاث مراحل: موازنة المعادلة، كتابة السطر العام، كتابة سطر المسألة وتركيب التناسب.
- سبع ألعاب: موازنة، كتل مولية، تناسب، صح/خطأ، ذاكرة، ترتيب الخطوات، وتحدٍّ شامل.
- مرسم تفاعلي يوضح تفكك الروابط وتشكلها وحفظ الذرات، مع بطاقة تفاعل قابلة للتنزيل.
- مسألة يومية، نقاط خبرة، مستويات، واثنتا عشرة شارة.
- ورقة عمل قابلة للطباعة وشهادة إنجاز.

## المنهاج

يعتمد الموقع مصطلحات كتاب الصف التاسع: المول، الكتلة المولية، عدد المولات `n = m/M`، الحجم المولي للغازات، والأمثال التفاعلية (المعاملات). ويضيف طريقة السطرين كتوسّع عملي للحسابات الكيميائية. تظهر الكتل الذرية المستخدمة في كل مسألة، كما في أمثلة الكتاب.

## التشغيل

لا يحتاج الموقع إلى بناء أو تثبيت. افتح `index.html` مباشرة، أو شغّل خادماً محلياً:

```bash
python -m http.server 4173
```

ثم افتح `http://localhost:4173`.

## الملفات

| الملف | الوظيفة |
|---|---|
| `index.html` | هيكل الصفحات والنوافذ |
| `css/styles.css` | التصميم والتخطيط والحركة |
| `js/chemistry.js` | قراءة الصيغ، الكتل المولية، وموازنة المعادلات |
| `js/data.js` | التفاعلات والأسماء والأسئلة والشارات |
| `js/app.js` | التفاعل: الدرس، المختبر، المكعبات، الألعاب، المرسم، والحفظ المحلي |

## ملاحظات

- تُستخدم الكتل الذرية المدرسية المقرّبة (H=1، C=12، N=14، O=16، Cl=35.5…).
- التقدم يُحفظ في `localStorage` داخل المتصفح.
- الصيغ المدعومة في محرّك الموازنة بسيطة: عناصر وأقواس وأرقام، دون شحنات أو هيدرات.
- ملف الكتاب المدرسي المستخدم للرجوع غير مضمّن في المستودع.
